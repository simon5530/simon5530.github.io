1. 適用範圍與使用對象

本政策適用於 TanSan-gog(Personal)，一項由擁有者自己操作的 Gog CLI／OpenClaw 個人整合。本工具不提供公眾註冊或代管其他人的 Google 帳號。本靜態網站僅提供說明文件，不接收 OAuth 回呼或處理 Google 帳號資料。

2. Google 資料存取與用途

經 Google OAuth 同意後，整合可在已授予權限內存取帳號基本身分資訊、Gmail 郵件與部分郵件設定、Calendar 活動、Drive 檔案、Contacts 聯絡資訊，以及 Sheets 與 Docs 內容。聯絡資訊亦可能包括 Google 的其他聯絡人或帳號有權存取的目錄資訊。實際可用資料取決於帳號、服務與授權範圍。

上述資料僅用於完成擁有者要求的郵件處理、行程管理、檔案與聯絡人整理、試算表分析或文件工作。取得授權不代表系統應持續收集全部資料；每次工作應只使用必要的資料。

3. 處理位置與服務供應商

Gog／OpenClaw 在擁有者管理的環境執行，並與 Google API 通訊。當工作使用已設定的雲端 AI、搜尋或其他工具服務時，完成該次工作所必要的內容可能傳送至相應供應商處理，因此本工具並非保證全程離線或僅在本機處理。

使用 Google 資料的工作必須先確認所選供應商與設定符合本政策及 Google API 使用者資料政策；若無法確認，應停止傳送該資料。資料不出售、不用於廣告，也不將透過 Google API 取得的資料用於訓練、微調或改善一般用途的 AI／機器學習模型。供應商之保留與處理條件須按實際使用服務確認，不能由本網站保證一律零保留。

4. 儲存、保留與存取

目前 Gog 設定使用作業系統鑰匙圈保護 OAuth 敏感憑證與權杖。原始憑證檔須由擁有者另行妥善保管，不得放入本公開網站或儲存庫。

依工作需要，輸出檔、快取、日誌或助理記憶可能在擁有者的環境保存；不承諾一律不保存或固定天數自動刪除。擁有者應依必要性保留、限縮存取並刪除不再需要的內容。必要的服務供應商處理與依法必須的揭露除外，不向其他人公開或任意轉交 Google 資料。

5. 撤銷授權與刪除

擁有者可隨時前往 Google 帳號的第三方連線管理移除本應用的存取權，並於 Gog 移除對應帳號授權。撤銷權限不會自動刪除先前產生的輸出、快取、日誌、記憶或備份；這些內容須在各保存位置另行清理。已傳送至供應商的資料依該服務的適用保留與刪除機制處理。
